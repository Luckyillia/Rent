# Forward Auto Rent — MTA Province #6

Макет сайта проката транспорта для игрового сервера MTA. React + Vite +
react-router-dom, без бэкенда — вся техника лежит в моковых данных.

## Запуск

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`.

Сборка:

```bash
npm run build
npm run preview
```

## Как устроена навигация

- `/` — главная: выбор категории техники (легковой, грузовой, общественный
  транспорт, мото, контейнеры, ивентовые машины).
- `/category/:categoryId` — список техники в категории: поиск, диапазон
  цены, сортировка. Если в категории пока нет техники — показывается
  пустое состояние («парк на пополнении»).
- `/car/:vehicleId` — отдельная страница машины: галерея, характеристики,
  оснащение, стадии тюнинга, цена в сутки/неделю, кнопка брони.

Всё это настоящие страницы со своим URL (react-router-dom), а не всплывающая
панель — можно поделиться прямой ссылкой на машину или категорию.

## Структура

```
src/
  data/
    categories.js        # список категорий (id, иконка, цвет, описание)
    vehicles.js           # моковый каталог техники + генератор стадий тюнинга
  utils/
    format.js              # форматирование денег и вместимости
    filterVehicles.js      # поиск/диапазон цены/сортировка внутри категории
  components/
    Header/, Footer/, Logo/         # общий каркас
    VehicleIcon/                     # силуэты техники: car/truck/bus/moto
    CategoryCard/                    # карточка категории на главной
    VehicleCard/, VehicleGrid/       # карточки техники в категории
    FilterPanel/                     # поиск + цена + сортировка
    Gallery/                         # "фотогалерея" на странице машины
    StagesList/                      # список стадий тюнинга с ценами
    Breadcrumbs/, EmptyState/
  pages/
    CategoriesPage/    # "/"
    CategoryPage/       # "/category/:categoryId"
    VehiclePage/         # "/car/:vehicleId"
  App.jsx                # роуты
  index.css               # тёмная тема, токены дизайна
```

## Дальше можно

- Подключить реальные фото вместо генеративной галереи в `Gallery.jsx`.
- Завести бэкенд/БД вместо `src/data/vehicles.js`.
- Сделать кнопку «Забронировать» в `VehiclePage.jsx` реальным запросом
  (сейчас она просто переключает локальное состояние).
- Добавить страницу личного кабинета с историей аренды.
