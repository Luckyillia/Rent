# Точечные правки (2 строки) — не отдельные файлы, а diff

Эти два файла НЕ переприсланы целиком, потому что меняется буквально
по одной строке. Примените вручную:

## 1. `src/index.css`

В самое начало блока `:root { ... }` (рядом с остальными токенами)
добавьте новую переменную:

```css
:root {
  /* ...существующие переменные... */

  /* Высота "слота" Breadcrumbs (margin-top 28px + строка текста +
     margin-bottom 28px) — используется, чтобы скелетоны страниц
     занимали то же место, что и реальный контент с крошками, а не
     были "приклеены" к хедеру во время загрузки. */
  --crumbs-block-height: 76px;
}
```

## 2. `src/pages/CategoryPage/CategoryPage.css`

Замените:

```css
.category-page__loading {
  margin-top: 28px;
}
```

на:

```css
.category-page__loading {
  margin-top: var(--crumbs-block-height, 76px);
}
```

(`VehiclePage.css` и `BookingPage.css` в этом пакете уже используют
эту переменную — их можно просто скопировать целиком, см. основной
README.)
